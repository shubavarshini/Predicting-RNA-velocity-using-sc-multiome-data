# Predicting-RNA-velocity-using-multiome-data
Running MultiVelo v0.1.3 recover_dynamics_chrom on multiome with alignment of all the objects, i.e., RNA, ATAC and LIAM.

Multivelo Model: RNA velocities were estimated from aligned scRNA-seq BAM files and GTF annotations by quantifying unspliced and spliced mRNAs using the Velocyto Python package (v0.17). The resulting individual sample LOOM files were subsequently merged into a single dataset using a custom loompy-based Python script to facilitate downstream MultiVelo analysis. ATAC-seq peaks were assigned to genes using Cell Ranger's feature linkage algorithm, which associates peaks to their target genes based on proximity and co-accessibility patterns. Peak counts within each gene's associated regions were aggregated to generate gene-level chromatin accessibility scores. Quality control was performed by removing cells with fewer than 500 total RNA counts and genes detected in fewer than 20 cells. RNA transcript counts were log-normalized, and the top 5,000 highly variable genes were identified using the Wilcoxon rank-sum test in Seurat v3 implementation. To synchronize the datasets, the ATAC data were subsetted to match the RNA data and  subsequently normalized using term frequency-inverse document frequency (TF-IDF). Principal component analysis (PCA) was performed on the RNA matrix to extract the top 30 components. A k-nearest neighbors (kNN) graph was constructed (k=30) to compute the first- and second-order moments for the RNA data, effectively smoothing the splicing kinetics. The same RNA-derived connectivity graph was used to knn-smooth (multivelo’s `knn_smooth_chrom`) the ATAC chromatin accessibility scores. Baseline RNA velocity was estimated using the scVelo package. Splicing dynamics were recovered, and velocities were computed using stochastic model (minimum R² = 0.02) to calculate cellular latent time and construct initial velocity graphs. Finally, the joint RNA and ATAC modalities were modeled using MultiVelo (`recover_dynamics_chrom`). This multi-omic dynamical model integrated the smoothed chromatin accessibility data with the RNA kinetics (configured with 500 anchors, 30 principal components, and a maximum of 5 iterations) to generate refined cellular lineage predictions. Genes with successful multi-omic velocity fits, the dataset was filtered to retain only those genes that possessed a valid model likelihood for either the RNA (fit_likelihood) or chromatin (fit_likelihood_c) modalities, ensuring the inclusion of dynamics driven by either transcriptomic or epigenomic regulation.

Trajectory Maturation, Latent Time Correlation, Phase Portraits: To visualise dynamic gene changes occurring during maturation of each lineage, we identified genes strongly driven by developmental time. For each lineage, we computed the Spearman correlation between every gene's expression profile and the cells' inferred latent time. We then selected the top 40 driving genes per lineage: the 20 genes most negatively correlated with latent time (representing early-stage suppressed drivers) and the 20 genes most positively correlated (representing late-stage activated drivers). Velocity streams and individual kinetic phase portraits were projected to validate lineage trajectories. Velocity streamline embeddings on UMAPs provide a macroscopic view of cellular transition probabilities. Alternatively, phase portraits (plotting Unspliced vs. Spliced RNA, or Chromatin vs. Spliced RNA) allows for visual confirmation that cells follow the expected kinetic shapes (e.g., almond-shaped curves or linear) required for velocity inference.

Statistical Ranking and Differential Driver Identification: highly specific marker genes, differential ranking was performed using a Wilcoxon rank-sum test, with significance defined as a False Discovery Rate (FDR) < 0.05. For broad categories, such as lineages and specific experimental days, we evaluated the top 100 significant genes per group. To ensure absolute specificity at this level, a strict mutual exclusivity filter was applied: a gene was only retained as a marker if it was completely absent from the top 100 marker lists of all other comparable groups. For higher-resolution such as specific cell-type clusters on a specific day, we evaluated the top 50 significant genes per cluster. To identify drivers unique to these micro-states, we applied a dual-restriction logic, first, genes were excluded if they were active in any cluster belonging to a different lineage. Second, to guarantee high specificity within a given lineage, a retained gene was permitted to be shared by a maximum of only three related clusters.
